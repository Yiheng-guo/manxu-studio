## 真实能力验证

- **AI 剧本**：本机已登录 Pi，使用实际可调用的 `openai-codex / gpt-5.5`，生成《把星星寄回家》的角色与 4 个分镜，约 23 秒。保存结果见 [ai-script-example.json](ai-script-example.json)。凭证不在仓库内。
- **本机中文配音**：使用 macOS `say` 的 Tingting 音色。音频检测有实际信号，非静音占位。
- **成片**：《开往明天的末班车》，4 镜、约 30 秒、1280×720、H.264 + AAC，含画面中文字幕与独立 SRT。FFmpeg 全片解码通过，浏览器播放器能加载，无媒体错误。
- **视觉检查**：检查工作台、分镜编辑与成片页；字幕抽帧可读，无中文缺字。截图见本目录 `screenshot-home.png`、`screenshot-storyboard.png`、`screenshot-export.png`、`film-frame.png`。

- macOS 是本次实际验证平台。Windows / Linux 真实设备验收未完成；GitHub Actions 的状态以仓库实际运行记录为准。
- 没有多用户鉴权、公网部署、口型动画或强身份锁定。不将本地运行或源码上传称为线上服务。
- 断线恢复、worker 重启恢复有实现和核心规则测试；没有进行长时间断网压力测试或大规模并发测试。
