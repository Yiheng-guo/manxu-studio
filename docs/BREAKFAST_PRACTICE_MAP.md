## 3. 可以真正借鉴的机制

### 3.1 多集的因果链与故事时间

每集记录“目标、阻力、可见选择、结果、集尾问题”，终章允许收束。角色目标与故事时间轴分别留存，检查“明天/后天/下午”等台词是否互相矛盾。预热片用于进入故事，不代替正片缺失的行动与因果。

适配漫序：现有单作品增加明确的集号与故事时间信息，在方法卡展示多集组织建议；只有实际实现多集管理与回归后才称为功能。不要为了故事完整而自动触发大批量付费生成。

### 3.2 小样前置与候选隔离

公开 SOP 建议先做 20–30 秒、同一角色同一场景、两句对话和一个动作接点的小样，验证高风险的脸、声音、口型与文字；小样失败先改参考或镜头设计再扩大。20–30 秒是该 SOP 的探索建议，不是所有项目的硬门槛。

所有生成视频均先标“候选”，按人物/声音/口型/连续性审阅后再进入制作版。保留原片和失败候选，不将生成完成自动等同验收通过。

适配漫序：素材来源与审核状态分开；候选入库需要源文件、版本、采用区间、限制和人工判断。当前静帧推拉制作流程不能以此宣称已具备真实视频模型集成。

### 3.3 角色、场景、道具起止状态

角色有稳定 ID 与主参考，场景有固定空间关系，道具记录数量、位置、持有者和进出镜状态。镜头卡显式记录起态 → 动作 → 终态，连接前镜与后镜；参考图在生成节点是否真的绑定，必须单独核查。

适配漫序：持续使用角色 ID 和镜头 ID，在镜头旁记录道具与相邻状态；文字状态检查可以定位矛盾，但不能替代实际视频/图片的视觉审查和锁脸能力。

### 3.4 源片区间与成片时间映射

JSON 清单以 `source/start/end` 管理原片，配合 `crop`、顺序和版本，由 FFmpeg 合成。镜头的画面与同期声使用同一源区间；重字与动作衔接问题不能只移音频。原片保存不覆盖，改动形成可回退的候选版本。

公开例子：第五集将女儿问句的镜头换成女儿露脸、妈妈仅作肩部前景，采用源片 2.8–7.2 秒，问句对应源片 4.6–5.8 秒；第一集对道具跳变的源片只采用 0–8 秒。这些是作者记录的修复参数，不是本次重新播放验证。

适配漫序：问题单记录“集号、成片时间、源镜头、源区间、当前版本、修复和复验”。当前静帧镜头没有真实源视频区间，需根据素材类型呈现相应字段，不伪造映射。

### 3.5 原声与叠加配音的显式状态

渲染源码能直接确认 `source_audio` 的 `native/ambient/mute` 三种模式和单独的 `voice_overs`：

- `native` 保留同镜同期声，正面可见嘴仍需人工核对自然度和归属。
- `ambient` 只是把源声音量降低，不是语音分离；含旧对白时不能据此说已去掉旧人声。
- `mute` 停用源声。画外/电话声单独记录入点、启用状态、音量、淡入淡出与效果。

源码支持画外项 `enabled:false` 停用和 300–3400 Hz 电话频段处理。公开第六集纸条段停用额外 WAV 并静音对应源区间，是防止两层人声的具体方法。滤波和响度调整不能修复说话人错配、口型或机械表演。

适配漫序：静帧旁白与真视频同期声需要不同规则；制作对象先标媒体类型，再确定音轨策略。不要把本地文字配音能力升级表述为口型同步能力。

### 3.6 关键文字由可控图层制作

公开技术说明描述：手机名单由 Pillow 绘制，用四个时间关键帧记录屏幕四角，逐帧线性插值，通过 NumPy 解八个透视参数贴回屏幕；暖色肤色遮罩和边缘羽化保留手指遮挡。适用于当时运动较小、四角可定位的镜头。

**公开仓库没有这部分 Pillow/透视修复的源码。** 本次可核实方法叙述，不可声称已拿到可直接运行的文字修复器。复杂遮挡仍需跟踪与遮罩。漫序已有字幕绘制与这类在移动屏幕上替换剧情文字是不同能力。

适配漫序：先增加文字可读性复核、人工记录和来源说明。若后续做叠图或视频文字修复，应独立实现、保留原片、新版本及前后比较，再做真实媒体验收。

### 3.7 技术检查与四种人工审片分工

可审阅源码包含格式/时间/裁切/音轨检查、720×1280/24 fps/48 kHz 统一输出、临时文件渲染、完整解码、内部切点近黑帧检查、拒绝覆盖现有输出。示例源片不公开，因此示例 JSON 能做结构校验；实际渲染需要自己的媒体。

内容验收分“静音看、闭眼听、带声逐镜、六集连看”，分别关注画面、声源、口型和跨集因果。机器检查不代替人眼人耳；ASR 疑似字句需要截短段复听，静音处可能出现假转写。

适配漫序：技术合成成功后保留内容待审；修复需要局部、相邻镜与整集复验。单作品跨集项显示不适用或未开展，不能强填通过。

### 3.8 扣点和有效片段的关系

每次生成需关联集/镜头、模型/参数、生成时间、交易 ID、扣点、退款、源文件、验收状态、有效采用秒数与返工原因。缺映射时不能计算可靠的镜头通过率、返工占比或每集成本。

适配漫序：先提供人工可记录、可导出的消耗与来源字段，分开实际积分、现金凭证、预算估算和未知。没有平台账单接口时不能自动显示“实时成本”；没有凭证也不能按 Token 推导现金。
