# 漫序 · FrameFlow

面向课程展示和个人创作者的本地 AI 漫剧工作台。用户提供故事，通过剧本、角色和分镜编辑控制内容，再生成或上传画面，合成带字幕和配音的动态漫画 MP4。

## 第一版范围
- 工作台首页：项目列表、搜索、创建项目、原创示例。
- 项目编辑器：故事设定、画风、画幅、角色设定、分镜顺序/时长/旁白/镜头/画面提示词。
- AI 剧本：配置服务端兼容接口，或本机已登录 Pi；结构化结果校验。
- 画面：逐镜上传、接入可配置图片接口，示例使用明确标注的预制原创 AI 画面。
- 成片：持久化后台任务，字幕、镜头推拉、配音、MP4 和 SRT 下载；缺画面时拒绝合成。
- 提供作品预览、项目 JSON 备份、答辩说明和复现步骤。

## 成功标准
创建 → 编辑 → 保存 → 获得画面 → 合成 → 播放/下载 → 刷新恢复。真实剧本模型调用至少验证一次；图片接口如缺凭证明确记为未实测，不用示例冒充实时生成。

## 边界
本地单用户课程 MVP，不是多租户 SaaS。动态漫画指静帧推拉+配音字幕，不宣称角色口型动画或图生视频。上传 GitHub 公开源码已获授权；不默认创建付费云资源。
