# 架构与接口

## 进程与状态
网页和 worker 使用同一个 SQLite 数据库。任务按提交顺序串行消费，避免个人电脑同时承载多个视频编码。项目编辑通过 revision 实现乐观锁，任务使用部分唯一索引保证同一项目只有一个 queued/running 任务。

API 使用幂等键恢复已创建任务。worker 保存产物时在数据库事务中重新检查任务是否仍为 running；取消后迟到的模型结果不能覆盖新编辑。最终产物与 succeeded 状态在同一事务提交。

刷新仅 GET 已有项目，不创建任务。浏览器的 disconnected 状态不代表后端失败。

## HTTP 契约

所有写请求只接受本机 Host 和匹配 Origin；本课程版本是单用户本地工具，不提供公共服务鉴权。

| 方法与路径 | 请求 | 响应 / 说明 |
|---|---|---|
| GET `/api/projects` | 无 | `Project[]` |
| POST `/api/projects` | `ProjectInput` 或 `{template:"demo"}` | 201 `Project` |
| GET `/api/projects/:id` | 无 | `{project,job}`，job 为最新任务或 null |
| PATCH `/api/projects/:id` | `ProjectInput + revision` | 更新后 Project；过期 revision 返回 409 |
| DELETE `/api/projects/:id` | 无 | `{ok:true}`；有活动任务返回 409 |
| POST `/api/projects/:id/jobs` | `{kind:"script"|"images"|"render"}` + `Idempotency-Key` | 202 Job；重复键返回原任务；键跨项目复用拒绝 |
| POST `/api/projects/:id/images` | multipart `shotId,revision,file` | 图片解码/重编码后返回 Project；10 MB 上限 |
| GET `/api/jobs/:id` | 无 | Job |
| POST `/api/jobs/:id/cancel` | 无 | Job；worker 停止处理，保留已完成素材 |
| GET `/api/assets/:project/:file` | 可选 Range | 文件流，206 支持拖动播放；不合法范围 416 |
| GET `/api/settings` | 无 | 只返回配置/服务状态，不回传凭证 |

错误统一为 `{error:{code,message}}`；无原始堆栈、供应商响应或密钥。

## 媒体流水线

1. 固定项目快照，拒绝缺画面的合成。
2. 将每镜画面裁切到目标比例，为字幕生成透明覆盖层。
3. macOS `say` 或配置的 TTS 产生旁白；检测音频时长。
4. 镜头时长取计划时长与配音长度的较大值。
5. FFmpeg 实现平滑推拉、覆盖字幕，编码 H.264 / AAC。
6. 合并片段并写入 MP4 `faststart`，输出独立 SRT。

此流程只处理静帧动态漫画，不包含图生视频、角色骨骼动画或唇形同步。
