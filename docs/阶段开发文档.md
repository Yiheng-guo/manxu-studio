## 接口概要
- GET/POST /api/projects；GET/PATCH/DELETE /api/projects/:id
- POST /api/projects/:id/jobs，kind=script|images|render，携带 Idempotency-Key
- POST /api/projects/:id/images，multipart 分镜图片
- GET /api/jobs/:id；POST /api/jobs/:id/cancel
- GET /api/assets/:project/:file，媒体文件与 Range 播放
- GET /api/settings，仅返回是否配置和能力状态，不回传凭证

## 状态
项目草稿/已分镜/已有画面；任务 queued/running/succeeded/partially_succeeded/failed/cancelled。浏览器 disconnected 独立处理。分镜生成后由用户编辑确认，再发起画面与合成。
