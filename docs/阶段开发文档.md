## 接口概要
- GET/POST /api/projects；GET/PATCH/DELETE /api/projects/:id
- POST /api/projects/:id/jobs，kind=script|images|render，携带 Idempotency-Key
- POST /api/projects/:id/images，multipart 分镜图片
- GET /api/jobs/:id；POST /api/jobs/:id/cancel
- GET /api/assets/:project/:file，媒体文件与 Range 播放
- GET /api/settings，仅返回是否配置和能力状态，不回传凭证

## 状态
项目草稿/已分镜/已有画面；任务 queued/running/succeeded/partially_succeeded/failed/cancelled。浏览器 disconnected 独立处理。分镜生成后由用户编辑确认，再发起画面与合成。
# 第二版：个人实践沉淀工作台 · 2026-10-03

目标：从研究问题出发，保存证据与判断，用统一样例比较模型，关联创作项目，记录问题、局部修复与复测，再导出可继续使用的实践档案。

范围：新增实践总览、研究/评测/质量/分享记录与六项 Skill 方法库；保留脚本、角色、分镜、图片、配音和成片。记录属于个人工作区，公开示例明确标识，不预填实习业绩或模型得分。

接口：GET /api/records；POST /api/records（客户端 UUID 幂等创建）；PATCH /api/records/:id（revision 防覆盖）；DELETE /api/records/:id。项目关联由服务端记录内容指纹，内容改变后原审阅标记需复核，单纯合成任务不会误标过期。删除创作项目保留实践记录、解除关联。

状态：列表加载/空/失败；记录 draft/active/retest/closed；提交期间防重复，失败保留表单；过期 revision 提示重新载入；重新打开 URL 恢复选中记录。闭环包含目标、输入、验收条件、观察结果、行动和证据，评测保留原始输出与版本，现金成本未知不等于零。

验收：新建研究记录→关联创作项目→保存原始评测记录→在相同 caseId 下对照→登记 Bad Case→修复并记录局部/相邻/全片复测→刷新仍保留→导出 JSON/Markdown。检验未知值、非法链接、并发冲突、幂等提交、项目变更复核。执行 lint/typecheck/test/build，实际浏览器检查多尺寸、键盘、保存、刷新、跳转和原成片流程。

风险与回退：不迁移旧 projects/jobs 表；新增记录表。无公司原始材料时仅使用用户提供的经历说明、公开方法及明确标注的教学示例。没有真实多模型输出不能声称选型结论或质量提升；没有凭证不估现金成本。当前仍为本机单用户产品。
