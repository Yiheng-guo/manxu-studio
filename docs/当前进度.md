# 当前进度

## 2026-10-03：个人实践工作台 v2 迭代

产品方向从课程创作 MVP 延展为个人 AIGC 产品实践工作台，连接研究与需求、模型评测、作品制作、质量复测、知识分享和六项 Skill 方法。技术包继续沿用原稳定版本，v2 是产品与文档迭代名。

**本轮新增实现已通过34项自动测试、lint、类型检查、生产构建与核心浏览器人工验收；详细结果及限制见 [验证记录](验证记录.md)。** 本页不沿用课程测试数量宣布 v2 通过，不新增未经执行的模型质量、成本节省或用户实验结论。

新增内容：

- 统一总览和五类实践记录（研究、评测、问题、阶段审阅、分享）；SQLite 持久化与项目关联。
- UUID 幂等创建、record revision 冲突保护、完整版本历史查看与导出；删除项目后保留实践历史、解除关联。
- 项目内容变化后提示需复核，普通修改记录不改变原审阅锚点；实际复查后显式确认当前 project revision，防止无意识清除需复核状态。
- 人工模型评测台账：任务、Prompt/模型版本、标准、原始结果、完成判断和可选指标；未知留空，费用有值必须附依据。
- 人工镜头连续性卡：角色、道具、进入/离开状态、准确台词；用于审阅，不自动识别图像或生成独立角色配音。
- 媒体定位与返工卡：集/片段、源镜头、区间、生产阶段、问题、声轨建议、返工范围与局部/相邻/全片检查；积分与尝试次数按人工来源记录，不换现金。
- 新本地合成保存编码镜头区间，可按问题秒数回到镜头；时长保留两位小数，拼接与帧舍入可能有偏差，需播放器核边界。旧片无编码区间时仅显示计划。
- 六项公开方法与源码入口、Markdown 分享草稿及 JSON 实践档案导出；不自动安装或执行 Skill。

来源：[开源研究](OPEN_SOURCE_RESEARCH_2026-10-03.md)、[实习资产梳理](INTERNSHIP_ASSET_MAP.md)、[早餐外部实践映射](BREAKFAST_PRACTICE_MAP.md)。本轮借鉴 promptfoo、LangGraph.js、Toonflow、MoneyPrinterTurbo 的机制，独立实现，不复制上游源码或引入其运行时。

来源边界：快看实习经历为用户提供的自述，漫序是后续个人实现；不是快看内部系统或企业业绩证明。《下次做给我吃》在另一个平台制作，平台未由用户指名，只作个人方法与公开复盘；6 集、403 秒、124 笔视频生成和 11,460 积分不计为漫序作品、调用或成本统计。

运行与发布：通过 `npm run dev` 启动网页和 worker，打开 [http://127.0.0.1:3210](http://127.0.0.1:3210)。**本轮尚未推送 GitHub，未部署公网服务。** 本地数据库、模型授权、配置和用户素材不自动公开。

当前未实现：自动批量模型评测、自动视听审阅、GPU 锁脸、口型动画、外部视频上传剪辑、自动停用声轨、Pillow 动态文字修复、多用户账号权限和完整多集排产。真实图片供应商及外部 TTS 的既有待联调状态保持；记录字段不等于执行能力。
