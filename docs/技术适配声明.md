# 技术适配声明

- 目标：可运行、可展示、可修改的个人漫剧创作工作台，采用最小端到端切片。
- 参考 MoneyPrinterTurbo：脚本→素材→语音→字幕→视频的分阶段流水线；用户提供压缩包版本 3d5f4e421927d61f3eac729cf4b711ac0b69d688，MIT。
- 独立实现：角色档案、逐镜画面提示词、人工编辑确认、漫画分镜工作台。未整包搬运参考项目或其商业广告和素材。
- Next.js 16.3.5、React 19.3.0、TypeScript strict、Tailwind 4.3.3、Lucide。版本依据 2026-09-22 npm/官方文档核对，锁文件记录实际安装。
- 为降低课程项目启动成本，后端偏离 Python 默认，采用 Next.js Route Handlers + 独立 Node.js worker，前后端共用 Zod 契约。
- Node 24 内置 SQLite（WAL）保存项目和任务；本地 data/ 保存媒体。后台独立进程不依赖浏览器连接；重启时将中断任务标为失败，保留已有素材，由用户选择重试。
- Sharp 和 FFmpeg 渲染字幕与合成，macOS 系统语音或可配置 TTS；没有语音能力时明确标为无配音。
- AI 凭证只在 .env.local；Pi 可选模式禁用工具和项目扩展，仅调用模型输出文本。请求验证、同源写入、上传图片解码重编码、服务端幂等与任务互斥。
- 视觉：暖白工作区、墨色侧栏、橙色重点、电影感漫画画面。先完成工作台与分镜代表页，再验收扩展。
- 发布范围：公开 GitHub 仓库；互联网多用户托管需另做账户权限、资源隔离和持久化部署。
# v2 适配补充 · 2026-10-03

漫序在现有创作工具上迭代为个人 AIGC 产品与创作工作台：把用户提供的快看漫画实习方法，与后续独立实现、公开 Skill、可复查的实践记录连接起来。保留 2026-09-22 课程 MVP 的历史，不将该系统描述为公司内部产品。

继续使用现有 Next.js / React / TypeScript / Lucide / SQLite 与独立 worker，不引入评测框架、GPU 模型或新供应商。导航、选中记录和关联项目放在 URL；记录在 SQLite，未提交表单为组件状态。研究、人工评测、质量复测记录共用受校验的记录接口；未知消耗与费用保存为 null，填写金额必须附计费依据。参考开源项目的机制，自行实现，不复制其代码。

视觉沿用深色侧栏、暖白画布与橙色强调，增加实践总览、研究台账、同任务模型对照、质量复测、六项方法资产。表单使用原生 dialog，覆盖加载、空、失败、冲突与刷新恢复。目标宽度 390 / 768 / 1280 / 1440。评测记录不是自动模型评分或公司 KPI；创作任务仍由真实 worker 执行。
